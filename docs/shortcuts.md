# 크롬 단축키 호환표 (M1)

구현 위치: `src/main/browser/Shortcuts.ts`. 셸과 각 탭 웹 콘텐츠 양쪽에 `before-input-event` 로
붙여 포커스가 어디 있어도 동작한다. `globalShortcut` 은 앱이 백그라운드일 때도 키를 가로채므로 쓰지 않는다.

## 동작하는 단축키

| 단축키 | 동작 | 크롬과 같은가 |
|---|---|---|
| `Ctrl+T` | 새 탭 | 같음 |
| `Ctrl+W` | 탭 닫기 (고정 탭은 닫히지 않음) | 같음 |
| `Ctrl+Shift+T` | 닫은 탭 복구 (최근 25개 스택) | 같음 |
| `Ctrl+L` | 주소창 포커스 + 전체 선택 | 같음 |
| `Ctrl+R` / `F5` | 새로고침 | 같음 |
| `Ctrl+Shift+R` | 캐시 무시 새로고침 | 같음 |
| `Alt+←` / `Alt+→` | 뒤로 / 앞으로 | 같음 |
| `Ctrl+H` | 방문 기록 (셸 패널 토글) | 크롬은 새 탭, Helm 은 패널 (ADR 0005) |
| `Ctrl+J` | 다운로드 (셸 패널 토글) | 크롬은 새 탭, Helm 은 패널 |
| `Ctrl+Shift+O` | 북마크 관리자 (셸 패널 토글) | 크롬은 새 탭, Helm 은 패널 |
| `Ctrl+D` | 북마크 토글 — 없으면 추가, 있으면 삭제 | 크롬은 편집 팝업, Helm 은 즉시 토글 |
| `Ctrl+F` | 페이지에서 찾기 | 같음 |
| `Ctrl+P` | 인쇄 대화상자 | 같음 |
| `Ctrl+Shift+S` | 현재 페이지를 PDF 로 저장(다운로드 폴더) | 크롬에 없음 (인쇄→PDF 대신 한 단계) |
| `F12` / `Ctrl+Shift+I` | 개발자도구 (별도 창) | 같음 |
| `Ctrl` `+` / `-` / `0` | 확대 / 축소 / 배율 초기화 (0.25~5배) | 같음 |
| `Ctrl+1`~`Ctrl+8` | n번째 탭으로 | 같음 |
| `Ctrl+9` | 마지막 탭으로 | 같음 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 탭 (순환) | 같음 |
| `F9` | 읽기 모드 토글 | 크롬에 없음 (Firefox 와 같은 키) |
| `Ctrl+Shift+D` | 테마 순환 (시스템 → 어둡게 → 밝게) | 크롬에 없음 |
| `Ctrl+Shift+E` | 세로 ↔ 가로 탭바 전환 | 크롬에 없음 |
| `Esc` | 찾기 닫기 · 셸 패널 닫기 | 같음 |

## 마우스

| 동작 | 결과 |
|---|---|
| 탭 드래그 | 순서 변경. 고정 탭은 고정 구간 안에서만 움직인다 |
| 탭 가운데 버튼 클릭 | 탭 닫기 (고정 탭 제외) |
| 북마크바 항목 가운데 버튼 클릭 | 새 탭에서 열기 |

## 의도적으로 다르게 둔 것

- **내부 화면을 탭이 아니라 셸 패널로 띄운다.** 크롬은 `chrome://history` 같은 페이지를 탭에
  열지만, Helm 은 웹 콘텐츠 뷰에 preload 를 붙이지 않는다는 보안 기본값(CLAUDE.md)을 지켜야 한다.
  근거는 `docs/adr/0005-내부화면-셸패널.md`.
- **`Ctrl+D` 는 즉시 토글이다.** 편집 팝업(이름·폴더 지정)은 북마크 관리자에서 한다.

## 아직 없는 것 (M1 범위 밖)

- `Ctrl+Shift+N`(시크릿 창), `Ctrl+N`(새 창) — 창 여러 개는 M1 범위가 아니다.
- `Ctrl+Shift+B`(북마크바 토글) — 북마크가 하나라도 있으면 자동으로 보인다.
- `Ctrl+Shift+A`(탭 검색), `Ctrl+Shift+Delete`(인터넷 사용 정보 삭제) — 히스토리 화면의
  "전체 삭제" 버튼으로 대체.
