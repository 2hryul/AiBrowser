- **결정 사항**
  - **기본 세션의 파티션은 `persist:helm`** 을 그대로 유지하고 이름 있는 세션만
    `persist:helm:<name>`. `persist:helm:default` 로 바꾸면 M0 부터 쌓인 로그인이 전부 날아간다
  - **세션을 바꿔도 이미 열린 탭은 그대로다.** 보고 있는 화면의 계정이 뒤에서 바뀌는 것이 더 위험하다
  - **자동 체크포인트도 마지막 진행 커서를 실어 나른다.** 커서 없이 덮이면 "최근 체크포인트에서
    재개" 가 처음부터 다시 하기가 된다
  - **스레드에는 도구 결과 전문을 넣지 않는다**(문자열 200자·배열 5개 요약). 400페이지 순회로
    DB 가 수십 MB 로 불어난다. 전문은 감사 로그에 있다
  - **결과표는 DB 에 매 행을 쓰지 않는다.** 수집 중에는 초당 여러 번 바뀌고, 남아야 하는 시점은
    체크포인트뿐이다
  - 마이그레이션은 `migrations/` 의 번호 붙은 **`.ts`** 파일. `.sql` + `?raw` 는 번들에 파일 로딩
    경로를 하나 더 만든다(이번 세션에 지연 `require` 로 같은 함정을 겪었다)
  - MCP 에 **`X-Helm-Thread` 헤더** 추가 — 연결마다 새 스레드가 생기면 재시작 후 이어가기가 불가능
