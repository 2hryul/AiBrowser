## 4. 설계 판단 — 이어받는 사람이 알아야 할 것

### 4-1. 비밀번호는 **CSV 경로만** 구현했다 (DPAPI 아님)

`goals/GOAL-M4c.md` 는 "CSV **또는** DPAPI 복호화" 를 허용하지만, 같은 파일의
FIXED DECISIONS 는 lint 예외를 **`Login Data` 에 대해서만** 열어 준다.
`DPAPI`·`CryptUnprotectData`·`os_crypt` 는 `eslint-rules/no-credential-files.mjs` 의
`CRYPTO_IDIOMS` 에 그대로 남아 **예외 밖**이다.

→ DPAPI 경로는 이 규칙 아래에서 **작성할 수 없다.** 그래서 Chrome 내보내기 CSV 로 갔고,
그 경로는 `Login Data` 를 아예 건드리지 않아 예외조차 필요 없다.

예외 기구 자체는 조건 4가 요구하므로 만들고 테스트했다(주석만으로는 안 열린다 —
`// policy:password-import` 주석과 감사 로그 호출이 **둘 다** 있어야 한다).
나중에 DPAPI 를 켜려면 복호화 관용구 차단을 **의식적으로** 푸는 별도 결정이 필요하다.

### 4-2. `CredentialStore` 는 의존성 0 이다

`keytar` 를 붙이면 네이티브 빌드 + 라이선스 심사(STOP CONDITIONS)가 따라온다.
Windows 의 `advapi32.dll` `CredWrite` 를 PowerShell P/Invoke 로 부른다.

**실제 자격증명 관리자에 대고 시험하며 두 개를 고쳤다** — mock 만 썼으면 못 잡았다:

1. 스크립트와 비밀번호를 같은 stdin 으로 보내면 `-Command -` 가 **stdin 전체를 스크립트로**
   먹어 `ReadToEnd()` 가 빈손이 된다 → 스크립트는 `-EncodedCommand` 로
2. `CredDeleteW` 의 `DllImport` 에 `CharSet=Unicode` 가 빠져 기본 Ansi 로 마셜링되며
   **삭제가 조용히 실패**했다. `[void]` 가 그 실패를 삼키고 있었다

비밀번호는 **stdin 으로만** 간다(argv 에 실으면 프로세스 목록에 보인다). 임시 파일도 없다.

### 4-3. 정책 게이트는 **IPC 에도** 있다

`ipcMain.handle(IPC.importPasswords, ...)` 가 `policy.snapshot().allowPasswordImport` 를
직접 확인한다. 화면에서 항목을 숨기는 것만으로는 부족하다 — renderer 를 믿고 게이트를
UI 에만 두면 IPC 를 직접 불러 우회할 수 있다.

### 4-4. UA 는 스푸핑이 아니다

`oauth_modal` 은 Electron 기본 UA 에서 **`Electron/x.y`·`Helm/x.y` 토큰만 뗀** 표준
Chromium UA 를 쓴다(`stripElectronToken`). 다른 브라우저인 척하는 문자열을 만들면
봇 탐지 우회가 되고 그건 금지다(불변 조건 9). 이 구분을 지키는 테스트가 `tests/login.test.ts` 에 있다.

### 4-5. `external` 은 두 군데서 조인다

- 화이트리스트 밖 호스트는 **브라우저를 열기 전에** 거부한다(열고 나서 후회하면 늦다)
- 외부에서 로그인했더라도 Helm 세션이 안 섰으면 **`inapp` 으로 되돌린다** —
  그 쿠키는 그 브라우저 것이라 "했으니 됐겠지" 로 넘기면 사용자는 로그인했다고 믿고 계속 실패한다

### 이 저장소에서 자주 걸리는 함정

- **heredoc 백슬래시**: `bash <<'EOF'` 안의 `\n` 이 실제 줄바꿈으로 바뀐다.
  긴 패치는 python 스크립트를 **파일로 써서**(Write 도구) 실행하는 편이 안전하다
- **CRLF**: 파일은 CRLF 다. 패치 스크립트는 LF 로 정규화 후 CRLF 로 되돌린다
- **Electron 잠금**: 앞 실행이 남은 `electron.exe` 가 단일 인스턴스 잠금을 쥐면 다음 실행이
  조용히 죽는다. E2E 전에 `taskkill //F //IM electron.exe //T`
- **Playwright 워커 재시작**: 판정 `expect` 가 깨지면 워커가 새로 뜨고 모듈 상태가 날아간다.
  측정값은 회차마다 파일에 **합쳐서** 저장할 것(`scripts/agent-scenarios.ts` 의 `saveSummary` 참고)
