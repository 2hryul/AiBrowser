- **결정 사항**
  - **읽기 도구는 `inverse` 를 요구하지 않는다.** lint 규칙이 `sideEffect: 'read'` 를 건너뛴다.
    읽기는 되돌릴 대상이 없고 `irreversible: true` 로 두면 페이지를 읽을 때마다 승인을 요구한다
    → 규칙의 의도와 어긋난다. 근거는 ADR 0002
  - **사이트 접근 승인은 범위와 무관하게 그 실행 동안 유지**(`markVisited`)한다. 매 페이지 이동마다
    묻는 설계는 승인 피로를 만들고, 피로해진 사람은 읽지 않고 누른다. 쓰기 행위는 이 완화와
    무관하게 매번 판정한다
  - **`blocked_by_policy` 를 감사 로그의 결과로 남긴다.** 로그만 보고 "왜 안 됐나" 를 알 수 있어야 한다
  - 자동 승인 플래그는 만들지 않았다. 앱 종료 시 대기 중 승인은 `Approval.rejectAll()` 로 **거부** 처리
